# MonoTorrent Documentation

This repository contains comprehensive documentation for [MonoTorrent](https://github.com/alanmcgovern/monotorrent), a BitTorrent library written in C#.

## Getting Started

If you're new to MonoTorrent, we recommend starting with:

1. [Installation Guide](user_guide/installation.md) - How to add MonoTorrent to your project
2. [Basic Usage Guide](user_guide/basic_usage.md) - Quick start with essential operations
3. [Simple Client Tutorial](tutorials/simple_client_tutorial.md) - Step-by-step guide to building a client
